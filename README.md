# 武汉理工大学南湖图书馆座位预约助手 🎓

跨平台（Linux / Windows / macOS）的武汉理工大学南湖图书馆抢座/选座脚本。通过 `opencli` 复用本地浏览器（如 Edge/Chrome）的登录态，免去密码配置和验证码烦恼，支持按需求时长智能刷座。

## ✨ 特性

- **智能时长筛选**：支持设定“必须满足的时长”（例如要求至少预约 420 分钟或直接到晚上 22:00），如果不满足条件，脚本会持续监控刷新，直到有符合要求的座位释放。
- **无痛身份认证**：借助 `opencli`，直接拉起浏览器进行统一身份认证。后续自动复用 Cookie/Token，安全且免除验证码困扰。
- **双模操作**：
  - **交互式向导**：小白友好，直接运行脚本按回车即可完成配置。
  - **命令行参数**：适合极客和定时任务，一行命令直接起飞。
- **精细化控制**：支持指定楼层、开始时间、刷新频率、最大尝试次数，甚至支持避开特定“雷区”座位（内置屏蔽部分位置）。
- **确认模式**：支持找到座位后“自动秒抢”，或“弹窗手动确认”（防止乱占座被关小黑屋）。

## 🛠️ 依赖与安装

请确保你的电脑上已经安装了 **Python 3.8+** 和 **Node.js**。

**1. 安装 Python 依赖：**
```bash
pip install requests
```

**2. 安装 opencli（用于接管浏览器登录态）：**
```bash
npm install -g @jackwener/opencli
```
> **提示**：首次使用 opencli 可能需要进行简单的环境配置。关于 opencli 的工作原理、配置详情及完整文档，请参见 [opencli 官方 GitHub 仓库](https://github.com/jackwener/opencli)。

## 🚀 使用流程与运行模式

### 核心运行流程
无论使用哪种模式，脚本的整体运行流程如下：

1. **启动脚本**：在终端执行命令。
2. **浏览器登录**：首次运行或登录态失效时，`opencli` 会自动弹出一个浏览器窗口并跳转到座位预约系统的登录页。
3. **完成认证**：在这个浏览器窗口中，手动输入账号密码完成统一身份认证。
4. **脚本接管**：登录成功后，终端提示登录成功。此时脚本已自动提取 Token，开始在终端后台高频刷新抢座。你可以把弹出的浏览器放一边。
5. **抢座成功**：抢到后终端会打印座位详情，然后脚本自动退出。中途如需停止请按 `Ctrl+C`。

---

### 🟢 模式一：交互式引导
最简单的使用方式，无需记忆参数。直接在终端运行：

```bash
python whut-seat.py
```
运行后，脚本会一步步询问需要的配置。在任何问题处直接按回车，都会选择最常用的默认选项，例如今天、全部楼层、现在开始、最长时长、自动确认。

### 🔴 模式二：命令行直达
适合熟悉参数后一键运行，或者配合定时任务使用：

```bash
# 抢七楼，从现在开始，一直预约到晚上 22:00（-t -1），无限循环尝试
python whut-seat.py -f 7 -t -1

# 抢六楼，预约 120 分钟，最多尝试 50 次后停止
python whut-seat.py -f 6 -t 120 --max-attempts 50

# 指定日期，全部楼层，找到符合条件的座位后弹出提示让你输入 y 确认，不自动预约
python whut-seat.py -d 2026-06-18 --no-auto-confirm
```

## ⚙️ 命令行参数说明

| 参数 | 缩写 | 默认值 | 说明 |
| :--- | :---: | :--- | :--- |
| `--floor` | `-f` | `0` (全部) | 楼层选项：`6` = 六楼，`7` = 七楼，其他数字 = 全部楼层 |
| `--date` | `-d` | 今天 | 预约日期，格式 `YYYY-MM-DD` |
| `--start` | `-s` | 自动最近 | 预约开始时间，格式 `HH:MM`。不填则自动对齐到下一个 30 分钟档 |
| `--duration` | `-t` | `0` (最长) | 预约时长（分钟）。**填负数（如 `-1`）表示一直预约到 22:00 闭馆** |
| `--interval` | | `3.0` | 刷新间隔（秒），每次请求会附带 ±1 秒的随机抖动防封 |
| `--max-attempts`| | `0` (无限) | 最大尝试次数，`0` 表示不限制，直到抢到或手动 `Ctrl+C` 退出 |
| `--no-auto-confirm`| | `False` | 关闭自动预约。找到符合条件的座位后，需在控制台输入 `y` 确认 |
| `--once` | | `False` | 仅尝试一次（相当于 `--max-attempts 1`） |
| `--session` | | `whut` | opencli 的会话名称（一般不需要改） |

## 💡 常见问题与注意事项

1. **黑名单机制**：频繁预约并退座会导致账号被图书馆系统拉入黑名单（暂停预约权限）。建议在测试时使用 `--no-auto-confirm` 参数，找到座位但不立刻预约。
2. **黑名单座位屏蔽**：脚本内硬编码跳过了部分用户反馈体验不佳的座位（如 001-005, 187-194）。如有需要，可直接修改脚本中的 `BLACKLIST` 集合。
3. **Token 过期**：脚本遇到 Token 过期会自动拉起页面重新刷新，属于正常现象。
4. **网络超时警告**：后台筛选时会查验每个座位的精确空闲时间线，如果偶尔遇到部分请求超时，脚本会自动静默跳过该座位并进行下一轮刷新。
